> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Cilj:** porodica i negovateljica rade nad istim demo stanjem, u istoj ili u dve kartice pregledača, na tržištu FI ili SR. Simulacija radi sa obe strane.

- **Ko je prijavljen:** `App.jsx` posle prijave grana po `user.role`. Koja uloga i koje tržište važe za karticu čuva `sessionStorage` (`src/data/demo.js`).

**Tehnologije:** React 18, Vite 8, shadcn/ui + Tailwind (`docs/patterns.md`), `vitest` (novo, samo za čiste funkcije).

**Spec:** `docs/superpowers/specs/2026-10-19-temelj-design.md` (krovni: `docs/superpowers/specs/2026-10-19-negovateljice-pregled.md`)

Ono što spec podrazumeva, a obični testovi ne pokrivaju, poređano po tome koliko je verovatno da zasmeta:

1. **Dve kartice na različitim jezicima.** Kartica koja primi stanje prevede datume kod sebe (`relanguage`) i to ne upisuje nazad. Inače bi se kartice prepisivale u krug. Test u zadatku 3 i provera u zadatku 5.

```js
import { setMarket } from './market';
import { startCare, withAnswers } from './familyStart';
import { demoAnswers, demoUser } from './demoCase';
import { agreeTerms, askCaregiver, arrangementOf, linkCard, latestRequest, allVisits, withdrawRequest } from './familyCare';

const fresh = () => withAnswers(startCare(demoUser), demoAnswers, demoUser);
const agreed = (id = 'sanna') => {
  let c = askCaregiver(id, 'Zdravo')(fresh());
  c = answerRequest(id, true)(c);
  c = sendTerms(id)(c);
  c = agreeTerms(id)(c);
  return linkCard(c);

describe('caregiver actions', () => {
  beforeEach(() => setMarket('FI'));

  it('a yes in Finland opens a cooperation that waits for terms', () => {
    const c = answerRequest('sanna', true)(askCaregiver('sanna', '')(fresh()));
    expect(latestRequest(c, 'sanna').status).toBe('accepted');
```

```js
// The demo's shared state, one per market: the family's person and what they
// pay, and the caregiver's other clients. Kept in localStorage so a reload
// keeps it and a second tab reads it; every save tells the other tabs over a
// BroadcastChannel, so the family in one tab and the caregiver in another see
// each other's doing at once. The last save wins: a demo, not a database.
// Without storage (a private window) it all still works in one tab, unkept
// (docs/superpowers/specs/2026-10-19-temelj-design.md).

export const VERSION = 1;
const key = (market) => `nana.demo.${market}`;
const CHANNEL = 'nana.demo';

const safe = (fn, fallback) => {
  try {
    return fn();
  } catch {
    return fallback;
  }
};

export function createStore({
  storage = safe(() => globalThis.localStorage, null),
  Channel = globalThis.BroadcastChannel ?? null,
  onStorage = typeof window !== 'undefined' ? (fn) => (window.addEventListener('storage', fn), () => window.removeEventListener('storage', fn)) : null,
} = {}) {
  const channel = Channel ? safe(() => new Channel(CHANNEL), null) : null;
  const listeners = new Set();

  const load = (market) => {
    const raw = storage ? safe(() => storage.getItem(key(market)), null) : null;
    if (!raw) return null;
    const parsed = safe(() => JSON.parse(raw), null);
    if (!parsed || parsed.v !== VERSION) return null;
    const { v, ...state } = parsed;
    return state;
  };
  const tell = (market) => channel && safe(() => channel.postMessage({ market }));
  const save = (market, state) => {
    if (storage) safe(() => storage.setItem(key(market), JSON.stringify({ v: VERSION, ...state })));
    tell(market);
  };
  const reset = (market) => {
    if (storage) safe(() => storage.removeItem(key(market)));
    tell(market);
  };

  // another tab saved: read what it left, for whoever watches that market
  const heard = (market) => listeners.forEach((l) => l.market === market && l.fn(load(market)));
  if (channel) channel.onmessage = (e) => e?.data?.market && heard(e.data.market);
  // the browser's own event, for a tab that missed the message
  onStorage?.((e) => {
    const m = /^nana\.demo\.(fi|sr)$/.exec(e?.key || '');
    if (m) heard(m[1]);
  });

  const subscribe = (market, fn) => {
    const l = { market, fn };
    listeners.add(l);
    return () => listeners.delete(l);
  };

  return { load, save, reset, subscribe };
}

export const store = createStore();
```

```js
import { useCallback, useEffect, useRef, useState } from 'react';
import { store } from '../data/store';

// The demo's state for one market, as React state: read from the store (or
// seeded), saved on every change, and replaced when another tab saves. What
// arrives from another tab goes through `onReceive` (the dates said in this
// tab's language) and is not saved back, or two tabs in two languages would
// rewrite each other forever.
export function useShared(market, seed, { onReceive = (s) => s } = {}) {
  const [state, setState] = useState(() => store.load(market) ?? seed());
  const receive = useRef(onReceive);
  receive.current = onReceive;

  // the first state is kept at once, so a second tab opened now reads it
  useEffect(() => {
    if (!store.load(market)) store.save(market, state);
    return store.subscribe(market, (next) => setState(next ? receive.current(next) : seed()));
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [market]);

  const update = useCallback(
    (fnOrValue) =>
      setState((s) => {
        const next = typeof fnOrValue === 'function' ? fnOrValue(s) : fnOrValue;
        if (next !== s) store.save(market, next);
        return next;
      }),
    [market]
  );
  return [state, update];
}
```
